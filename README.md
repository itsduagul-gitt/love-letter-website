# Love Letter Website 💌

An interactive love-letter website: a passkey screen, a wall of memories, a "together for" counter, a jar of reasons, "open when..." envelopes and a typewriter letter.

## How to use

1. Download `index.html`
2. Open it in any browser (Chrome, Safari)

Internet is only needed for the fonts. Everything else is inside the file.

## Customize

Open `index.html` in a code editor (like VS Code) and edit the block near the top of the `<script>`:

- `HER`: the name shown after unlocking (optional)
- `PASS`: the 4-digit passkey
- `SINCE`: your special date
- `LETTER`, `TL`, `REASONS`, `NOTES`: your messages

## Note

The passkey is stored in the file, so anyone who views the page source can read it. It's meant for fun, not for real secrets.
